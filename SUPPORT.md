# Getting help

- **Help center:** answers to common questions about accounts, credits and downloads are at https://tube2vid.com/help.
- **API documentation:** https://tube2vid.com/docs
- **Is a site down?** Check the [platform status page](https://tube2vid.com/status) before reporting a failed download.
- **Billing and API keys:** see [pricing](https://tube2vid.com/pricing) or contact support through the help center.
- **SDK, CLI or MCP bugs:** open an issue in the relevant repository using the bug report template.
